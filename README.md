# paper-viewer

영어 논문(PDF)을 열면 자동으로 한국어로 번역해, **왼쪽=영문 / 오른쪽=한국어**로 나란히 보여주는
개인용 이중(bilingual) 뷰어입니다. 대응하는 문단·문장이 **같은 행**에 놓여 스크롤이 항상 정렬되고,
**그림·표도 원문과 같은 위치**에 삽입됩니다.

- 번역은 **로컬 LLM(Qwen 계열, Apache-2.0)** 으로 수행 → 완전 무료 · 기업/상업 사용 무제약 · **논문이 외부로 나가지 않음**.
- 번역 결과는 **단일 HTML 파일로 내보내** GPU·서버 없이 어떤 기기(노트북·아이패드·안드로이드 등)에서든 열 수 있습니다.

---

## 주요 기능

### 📖 이중 뷰어
- 좌(영문)/우(한글)를 **행 단위로 짝지은 그리드** → 단일 스크롤로 좌우가 항상 같은 위치.
- **그림·표**를 원문과 **동일한 위치**에 전폭으로 삽입(벡터 그래픽까지 이미지로 렌더, 멀티패널은 하나로 묶음).
- **문장 단위 양방향 하이라이트**: 문장을 클릭하면 좌/우 대응 문장이 동시에 **연두색 형광펜**으로 표시(다시 클릭/빈 곳 클릭 시 해제).
- **그림·표 설명 말풍선**: 그림/표를 클릭하면 캡션 기반의 쉬운 한국어 설명(💡)을 말풍선으로 표시.
- **영문 보기 토글**(한국어만 전체 폭으로 보기), **글자 크기 조절(A− / A+)**.

### 🌐 번역 (로컬 LLM)
- **GPU 성능 기반 모델 자동 선택** — 이 머신의 VRAM에 맞춰 가장 좋은 엔터프라이즈-안전(Apache-2.0) 모델을 고름.
- **런타임 헬스체크 + 자동 폴백** — 우선 모델(Qwen3)이 해당 머신에서 실제로 구동되는지 점검하고, 안 되면 동급 Qwen2.5로 자동 전환.
- **용어집(glossary)** — 핵심 전문용어를 일관된 한국어로 번역.
- **문장 단위 1:1 정렬 번역** — 좌/우 문장 상호 하이라이트를 위한 정렬 데이터 생성.
- **언어 유출 방어** — 한자/중국어/일본어/키릴 등 비한국어가 섞이면 감지해 재시도·교정·구간치환으로 제거.
- **참고문헌 처리** — 저자·저널·연도는 영문 유지, **인용 논문 제목만 한국어로 번역**(하이라이트 제외).
- **저자·소속·이메일**은 번역하지 않고 영문 유지, 반복되는 러닝헤더/푸터는 자동 제거.

### 💾 캐시 & 이식성
- 논문당 파싱+번역은 **1회**만. 이후 `cache/`에서 **즉시** 로드(목록에 ✓).
- 용어집을 수정하면 **그 용어가 든 문단만** 자동으로 다시 번역.
- **단일 HTML 내보내기** — 번역·그림·뷰어를 통째로 담아 어떤 기기에서든 오프라인으로 열림.

## 준비 (최초 1회)

1. **Python 패키지**
   ```
   pip install -r requirements.txt
   ```
2. **Ollama** (로컬 번역 엔진) — OS별 설치:
   - **Linux / macOS**
     ```
     curl -fsSL https://ollama.com/install.sh | sh
     ```
   - **Windows** (PowerShell)
     ```
     irm https://ollama.com/install.ps1 | iex
     ```
   - 또는 <https://ollama.com/download> 에서 설치 파일을 받아 설치.

   설치 후 백그라운드 서비스가 자동 실행됩니다. 실행되지 않으면 별도 터미널에서 `ollama serve` 로 기동하세요.

   - **모델은 자동으로 선택·다운로드됩니다.** VRAM에 맞춰 아래 티어에서 고릅니다(모두 Apache-2.0):

     | VRAM | 우선(Qwen3) | 대체(Qwen2.5) |
     |------|-------------|----------------|
     | 32GB+ (예: RTX 5090) | qwen3:32b (dense) | qwen2.5:32b |
     | 24GB (3090/4090) | qwen3:30b-a3b (MoE) | qwen2.5:32b |
     | 16GB+ | qwen3:14b | qwen2.5:14b |
     | 8GB+ (예: RTX 3080) | qwen3:8b | qwen2.5:7b |
     | 4GB+ | qwen3:4b | qwen2.5:3b |

     > 24GB는 dense 32B(Q4 ~22–23GB)도 아슬아슬하게 올라가지만, 모니터 연결·긴 컨텍스트에서
     > CPU 오프로드로 느려질 수 있어 **MoE(30b-a3b, ~18GB)** 를 기본값으로 둡니다(32B급 품질+빠름).
     > dense 32B를 꼭 쓰고 싶으면 `PAPER_VIEWER_MODEL=qwen3:32b` 로 강제 지정하세요.

   - 우선 모델이 그 머신에서 실제로 구동되는지 **자동 점검** → 안 되면 동급 **Qwen2.5로 자동 폴백**.
     판정 결과는 `cache/model_health.json`에 기억되어 이후 재점검하지 않습니다.
   - GPU가 없어도 **이미 번역된 논문을 보는 것**은 가능합니다(번역만 GPU 필요).

   **환경변수(선택)**
   - `PAPER_VIEWER_MODEL=qwen2.5:14b-instruct` — 특정 모델 강제 지정
   - `PAPER_VIEWER_ENGINE=qwen2.5` — Qwen3를 건너뛰고 Qwen2.5만 사용
   - 우선 모델을 다시 시도하려면 `cache/model_health.json` 삭제 후 재실행

## 사용법

1. 읽을 논문 PDF를 `papers/` 폴더에 넣습니다.
2. 서버 실행:
   ```
   python server.py
   ```
3. 브라우저에서 <http://localhost:8000> 접속 → 논문을 고르고 **열기**.
   - 처음 여는 논문은 파싱 + 번역이 진행됩니다(진행률 표시). 완료되면 좌·우로 표시됩니다.
   - 한 번 처리한 논문은 다음부터 **즉시** 열립니다.

### 다른 기기에서 보기 (GPU 불필요)
한 번 번역한 논문은 **단일 HTML 파일**로 내보내 어느 기기에서든 열 수 있습니다.
- 뷰어 툴바의 **⬇ 내보내기** 버튼, 또는
  ```
  python -m pipeline.export <paper_id>
  ```
- 결과 파일(`exports/<제목>.html`)에는 번역·그림·뷰어(문장 하이라이트·설명 말풍선)와
  **번역에 사용된 모델 표시**가 모두 내장되어, **서버·GPU·인터넷 없이** 파일만 열면 그대로 동작합니다.

### 딥링크(URL 파라미터)
- `?doc=<id>` — 캐시된 논문 바로 열기
- `&block=<n>` — 특정 블록으로 스크롤 / `&hl=<블록>-<문장>` — 특정 문장 하이라이트 / `&open=<블록>` — 그림/표 설명 열기

## 프로젝트 구성

```
server.py                 로컬 웹 서버(FastAPI). 파싱+번역 조율, 진행률 SSE, 내보내기, 뷰어 제공
glossary.json             영어→한국어 용어집(직접 편집 가능)
pipeline/
  parse.py                PDF → 읽는 순서로 정렬된 블록(텍스트/제목/캡션/그림/표), PyMuPDF
  translate.py            블록 번역(문장 정렬·용어집·언어가드·참고문헌·그림설명), 문단 캐시
  model_select.py         GPU(VRAM) 기반 모델 자동 선택(Qwen3 우선/Qwen2.5 폴백)
  export.py               번역 결과를 단일 HTML(자체 완결형)로 내보내기
web/
  index.html / style.css / viewer.js   좌·우 정렬 그리드 뷰어(하이라이트·말풍선·내보내기)
papers/                   여기에 논문 PDF를 넣습니다              (gitignore)
cache/                    처리 결과(블록·번역·그림 이미지)·번역메모리·모델판정  (gitignore)
exports/                  내보낸 단일 HTML                        (gitignore)
```

---

## 동작 원리 (요약)
- **parse.py** — PyMuPDF로 각 페이지의 텍스트 블록 위치(bbox)를 읽어 **단(column) 조판을 인식**하고 읽는 순서를 복원.
  그림·표는 벡터 그래픽까지 포함해 영역을 이미지로 렌더링, 인접 멀티패널은 하나로 묶음. 반복 러닝헤더/푸터 자동 제거.
- **translate.py** — 문단을 `[n]` 번호로 **문장 1:1 정렬 번역**(용어집 주입), 참고문헌은 제목만 번역.
  비한국어 유출은 5단계(재시도→문장분할→한글교정→구간치환)로 방어. 결과는 문단 단위로 캐시.
  간헐적 생성 멈춤에 대비해 타임아웃 재시도 + 블록별 폴백(실패 시 영문 유지)으로 항상 완주.
- **model_select.py / server.py** — VRAM 감지로 모델 티어 선택, 헬스체크로 실제 구동 가능한 모델 확정(폴백 판정 영속).
- **뷰어** — 블록을 좌(영문)/우(한글) **행 단위로 짝지어** 렌더 → 스크롤 자동 정렬. 문장 span 공유로 상호 하이라이트.

## 라이선스 메모
- **번역 모델(Qwen2.5 / Qwen3)** — Apache-2.0. 상업/기업 사용에 제약 없음.
- **PyMuPDF** — AGPL-3.0. 내부/개인용 사용은 무료·무제한이며, 소프트웨어 자체를 외부 배포하거나
  네트워크 서비스로 제공할 때만 AGPL 의무가 발생합니다.
- 논문 PDF 원본(출판사 저작물)과 번역 결과물은 저장소에 커밋하지 않습니다(`.gitignore`: `papers/`, `cache/`, `exports/`, `*.pdf`).

## 참고
- Qwen3는 라이선스상 문제가 없으나, **Ollama 버전에 따라 특정 GPU에서 구동이 불안정**할 수 있습니다.
  그런 경우 자동으로 Qwen2.5로 폴백하므로 동작에는 지장이 없습니다.
